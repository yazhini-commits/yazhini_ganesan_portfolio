# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/portfolio.git
```

## Navigate to Project Folder

```bash
cd portfolio
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
